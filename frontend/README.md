# Frontend — Поиск по базе знаний

Веб-интерфейс для загрузки документов и полнотекстового поиска по ним. SPA на React + TypeScript, взаимодействует с backend через REST API.

## Стек технологий

- **React 18** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **React Router 6** — маршрутизация
- **Axios** — HTTP-клиент
- **Tailwind CSS** — стилизация
- **react-dropzone** — drag-and-drop загрузка файлов
- **react-infinite-scroll-component** — подгрузка результатов поиска

## Реализованный функционал

### Авторизация
- Страницы **Login** и **Register**, JWT-токен хранится в `localStorage`
- `ProtectedRoute` — редирект на `/login` при отсутствии токена
- Axios-интерцептор автоматически подставляет `Authorization: Bearer <token>` в каждый запрос и разлогинивает пользователя при ответе `401`

### Загрузка документов
- Drag-and-drop зона (`UploadArea`) с поддержкой множественной загрузки, реализована на `react-dropzone`
- Валидация на клиенте: только PDF/DOCX, ограничение размера
- Индикация прогресса и статуса (`UploadProgress`): «Загрузка…», «Индексация…», «Готово», «Ошибка»
- Список загруженных документов (`DocumentList`) с названием и датой загрузки

### Поиск
- Поле ввода запроса (`SearchBar`) — поиск запускается по кнопке и по `Enter`
- Результаты выводятся карточками (`SearchResults`): файл, номер страницы, фрагмент текста, оценка релевантности
- Подсветка совпадений жёлтым фоном (`HighlightText`)
- Подгрузка результатов постранично (10 на страницу) через infinite scroll
- Признак `from_cache` от backend — можно показать, что ответ пришёл из Redis-кэша
- Пустое состояние с сообщением «По вашему запросу ничего не найдено»

### Адаптивность
- Вёрстка на Tailwind CSS, корректно отображается в диапазоне 320px–1920px

## Установка и запуск

### Локально (без Docker)

```bash
cd frontend
npm install

cp .env.example .env
# указать адрес backend API, например:
# VITE_API_URL=http://localhost:8000

npm run dev
```

Приложение будет доступно на `http://localhost:5173`.

### Через Docker

```bash
# из корня репозитория
docker compose up --build
```

Frontend соберётся в статику и будет раздаваться через Nginx на `http://localhost:80`.

### Переменные окружения

| Переменная     | Описание                         | По умолчанию            |
|----------------|-----------------------------------|--------------------------|
| `VITE_API_URL` | Базовый адрес backend API         | `http://localhost:8000` |

Файл `.env.example` содержит шаблон — скопируйте его в `.env` перед запуском.

## Скрипты

| Команда           | Назначение                                      |
|--------------------|--------------------------------------------------|
| `npm run dev`       | Запуск dev-сервера с hot reload                  |
| `npm run build`     | Проверка типов (`tsc`) и продакшн-сборка (Vite)  |
| `npm run preview`   | Предпросмотр собранной продакшн-версии            |
| `npm run lint`      | Проверка кода ESLint                              |

## Сборка образа

```bash
docker build -t search-frontend ./frontend
```

Используется многоступенчатая сборка: Node.js собирает статику, финальный образ — Nginx, который её раздаёт (конфигурация в `nginx.conf`).
