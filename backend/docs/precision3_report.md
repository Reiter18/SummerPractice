# Отчёт по метрике Precision@3

---

## Что такое Precision@3

**Precision@3** — доля релевантных документов среди первых 3 уникальных результатов поиска:
Precision@3 = (кол-во релевантных документов в топ-3) / 3

## Интерпретация результатов

### Precision@3 = 0.33 — это максимально возможный результат

При данной конфигурации корпуса P@3 = 0.33 является **теоретическим потолком**, а не слабым результатом. Причина:

- Каждый запрос имеет ровно **1 эталонный документ** из 10
- Нужный документ **всегда занимает позицию #1** в результатах — это подтверждает корректность ранжирования
- Позиции #2 и #3 неизбежно заняты нерелевантными документами
- Формула: 1 релевантный / 3 позиции = **0.33**

Если бы нужный документ не попадал в топ-3, P@3 было бы 0.00.
